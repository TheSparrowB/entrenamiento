# TEXTO

Existen diversos estilos que se les pueden aplicar a los textos. Por ejemplo

```markdown
## Con esto creamos subtítulos.
#### Con esto crearemos títulos más pequeños.
*Con esto incluimos texto en cursiva.*
**Con esto crearemos texto en negrita.**
```

A partir de lo mostrado en el bloque de código, se mostrará lo siguiente:

> ## Con esto creamos subtítulos.
> #### Con esto crearemos títulos más pequeños.
> *Con esto incluimos texto en cursiva.* <br>
> **Con esto crearemos texto en negrita.**


<br>


## TÍTULOS

Los encabezados en el Markdown son muy importantes para poder estructurar el contenido que se va a mostrar. En el markdown existen 6 tamaños de encabezados.

```markdown
# Título principal
## Subtítulo (Primer subnivel)
### Segundo subnivel
#### Tercer subnivel
##### Cuarto subnivel
###### Quinto subnivel
```

Estos se muestran de la siguiente manera:

> # Título principal
> ## Subtítulo (Primer subnivel)
> ### Segundo subnivel
> #### Tercer subnivel
> ##### Cuarto subnivel
> ###### Quinto subnivel


<br>

## CITAS DE TEXTO

Para incluir citas, solo basta utilizar el símbolo ">" al inicio de cada línea nueva.

> Esta es una primera cita de ejemplo.

> Esta es una segunda cita.

<br>


## OTROS FORMATOS DE TEXTO

Se pueden también aplicar otros formatos de texto como *el texto en itálica o cursiva* así como **el texto en negrita**.

Para aplicar el texto en itálica, solo basta con agrupar el texto que se requiere formatear con un asterisco en cada extremo. Y, para el texto en negrita, se requiere agrupar el texto con dos asteriscos en cada extremo.

```markdown
*Texto en itálica.*
**Texto en negrita.**
~~Texto tachado~~
```

Siendo el resultado el siguiente:

> *Texto en itálica.* <br>
> **Texto en negrita.** <br>
> ~~Texto Tachado~~
