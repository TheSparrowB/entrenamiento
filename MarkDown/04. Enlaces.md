# ENLACES

También es posible incluir enlaces en los documentos utilizando markdown, aplicando la siguiente estructura

```markdown
[texto_del_ancla](dirección_url "Texto_flotante")
```

Por ejemplo, aquí estamos incluyendo dos enlaces siguiendo la estructura anterior.

[Este es el enlace, click aquí](https://www.swartzentrover.com/cotor/photos/pigs/pigsindex.htm "Click acá para ver cerdos!!!")

[Este es otro enlace, click acá](https://www.bugguide.net/node/view/15740 "Click para buscar bichos!!!")

Sin embargo, esto no es lo único que se pueden hacer con los enlaces, sino que también se pueden incluir imágenes, ya sean locales o de sitios que requieran obligatoriamente una conexión a internet. Por ejemplo:
