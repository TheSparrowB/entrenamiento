# TABLAS

La creación de tablas utilizando markdown es un proceso un poco complicado, no porque sea complejo crearlas, sino porque toma mucho tiempo hacerlas.

Para la creación de tablas es necesario utilizar caracteres como el **pipe (|)**, los **dos puntos (:)** y los **guiones (-)**, así como el uso del "TAB".

```markdown
|ID     |Nombre         |Especie        |Precio ($) |
|:-:    |-              |-              |-:         |
|1      |Chip           |Hámster        |35.00      |
|2      |Carmelo        |Pollo          |25.75      |
|3      |Chester        |Perro          |75.00      |
|4      |Tabby          |Gato           |30.00      |
|5      |Judy           |Conejo         |20.00      |
```

Por ejemplo, según el fragmento de código anterior, nos daría la siguiente tabla:

|ID     |Nombre         |Especie        |Precio ($) |
|:-:    |-              |-              |-:         |
|1      |Chip           |Hámster        |35.00      |
|2      |Carmelo        |Pollo          |25.75      |
|3      |Chester        |Perro          |75.00      |
|4      |Tabby          |Gato           |30.00      |
|5      |Judy           |Conejo         |20.00      |
