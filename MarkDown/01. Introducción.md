# MARKDOWN

Es un lenguaje para poder convertir texto plano a HTML. En el sector informático es muy utilizado para poder crear documentación y otros elementos.

Por ejemplo, este lenguaje es tan simple que con el uso de un simple "michi" (#), se pueden crear diferentes tamaños de títulos.

```markdown
# TITULO
```

Y se mostrará lo siguiente:

> # TITULO

Así de fácil es el uso del markdown. En los siguientes documentos se verán aplicaciones de **otros tipos de formatos**.
