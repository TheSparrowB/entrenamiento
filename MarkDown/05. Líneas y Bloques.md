# LINEAS

Es posible incluir líneas a partir de la unión de diversos caracteres.

```markdown
---
___
```

Los cuales, una vez renderizados se pueden ver así:

---
___

Y si se utilizacen debajo de unas letras, entonces las líneas y las letras se verían de la siguiente manera:

Utilizando guiones
---

Utilizando guiones abajo
___

<br>

Si bien, sin letras ambas líneas lucen igual. La forma de mostrarse cambia cuando existen letras sobre las líneas. Aspecto que se debe de tomar en cuenta al momento de aplicarlas.

# BLOQUES

Es posible insertar líneas de código en el markdown utilizando el símbolo (`).

`
    dbms_output.put_line('Esta es una simple línea de código');
`

Asimismo, es posible incluir líneas de código "en línea", es decir, a continuación o en medio de los párrafos. Por ejemplo, `print('Aquí se puede ver un fragmento de código')`. Y esos elementos pueden agregarse las veces que sea necesario.


Sin embargo, además de líneas de código, también existen bloques de código. Los cuales son implementados mediante el triple símbolo de las líneas de código (```).

```typescript
let numeroA = 5;
let numeroB = 7;

console.log(numeroA + numeroB);
```

Estos bloques tienen la particularidad de mostrar código como se ve en un editor. La sintaxis y el coloreo necesario depende del tipo de lenguaje de programación que se le indique al bloque.

```html
<body>
    <section>
        Este elemento es una <strong>sección</strong>
    </section>
</body>
```

```css
.carta {
    background-color: white;
    border-radius: 20%;
    color: black;
}
```
